本文汇总 kl-tools（KL Profile）自 **1.1.1** 之后各版本的更新内容，按大版本（功能版本）组织，补丁版本并入所属大版本。版本号取自 Xcode 工程的 `MARKETING_VERSION` 变更历史；1.1.1 发布于 2026-08-23，截至 2026-10-22，当前工程版本为 **1.9.0**。下文另行标注版本号提升后的开发中改动。

## 1.2.x（2026-08-27 起）

包含 1.2.0、1.2.1。

- **烘焙节奏（Pace）**：新增烘焙节奏参数，作为一条独立于产地、含水率与风味的调整基线。
- **官方模板与 RoR 调整**：引入官方模板库，新增曲线 RoR 调整与四阶段优化相关处理。
- **iPad 布局**：首次加入 iPad 布局适配。
- **修复**：风味目标存储、烘焙节奏与含水率回填、页面布局。

## 1.3.x（2026-08-31 起）

包含 1.3.0、1.3.1、1.3.2。

- **收藏（Profile Library）**：新增收藏功能，macOS 与 iOS 双端可用。
- **收藏同步**：收藏通过 CloudKit 在设备间同步。
- **重命名**：收藏中的 Profile 名称可重命名。
- **风味表现策略（FlavorExpression）**：引入独立于参数偏移的风味表现策略层。
- **修复**：RoR 平滑、iPad UI。

## 1.4.x（2026-09-05 起）

包含 1.4.0、1.4.1、1.4.2、1.4.3。

- **烘焙复盘（Recap）**：导入 `.klog` 生成烘焙日志，填写杯测反馈并生成自动调节建议。
- **复盘解锁**：复盘中的调节能力支持内购解锁。
- **kpro 文件名规则**：文件名改为与 Kaffelogic Studio 兼容（47 字节上限）。
- **klog / kpro 关联**：打开 `.klog` 时自动打开对应 `.kpro`；未匹配到时清空当前打开的 `.kpro`。
- **修复**：手动实际一爆、调整建议保存风味调节、自动调节文件名与 hash 逻辑、新建 Profile 按钮与收藏按钮解耦、macOS 鼠标滚轮事件、英文环境滚动字幕显示。

## 1.5.x（2026-09-12 起）

包含 1.5.0、1.5.1。

- **色值仪（Roast Color / Roast Score）**：新增相机色值仪，可测量整豆或咖啡粉的烘焙度。
- **小组件**：新增色值仪小组件（主屏 / 锁屏）与收藏小组件。
- **评分提示**：加入应用内评分提示逻辑。
- **修复**：导入 kpro 文件名逻辑、收藏抽屉交互性能。

## 1.6.x（2026-09-20 起）

包含 1.6.0、1.6.1、1.6.2、1.6.3。

- **豆卡分享**：以豆卡二维码导出 / 导入收藏，支持从相册识别豆卡。
- **收藏管理**：收藏列表支持批量删除。
- **卡片动效**：收藏页面卡片翻转曲线。
- **参数变动浮层**：调整“高级微调”参数时，出现对应烘焙结果变化的浮层动效。
- **修复**：收藏同步无法打开、豆卡 UI、收藏列表性能优化。

## 1.7.x（2026-09-25 起）

包含 1.7.0、1.7.1、1.7.2。

- **养豆管理**：在收藏的 Profile 中记录烘焙日期与养豆天数，查看进度，支持多批次记录、调整时间、提前结束与撤销结束；新增养豆总览，记录通过 CloudKit 在设备间同步。
- **养豆完成提醒**：可为养豆记录开启到期通知；iOS 系统设置中可选择咖啡豆提示音或系统默认声音。
- **风味表现预览**：新增明快、圆润、柔和、轻盈、馥郁等表现风格，保留当前烘焙度与风味配比，预览温度、风机、RoR 曲线及时间变化，确认应用后才修改当前方案。
- **参数与收藏交互**：优化移动端参数页面、收藏卡片与抽屉；海拔输入新增滚动标尺选择与确认交互。

## 1.8.x（2026-10-06 起）

包含 1.8.0、1.8.1、1.8.2、1.8.3、1.8.4。

- **咖啡品种（Beta）**：新增品种选择与曲线修正，结果明细显示品种调整，收藏、豆卡分享与重新打开 Profile 时保留品种信息。仅对有适用规则的品种追加有限的时间修正，仍需实烘验证。
- **生豆密度（Beta）**：可输入堆积密度（g/L），对预热与干燥时间进行有限修正，结果明细单列密度修正；密度参数随 `.kpro` 保存，重新打开不会重复补偿，旧文件保留原有行为。
- **风味推荐修正**：密度匹配仅作为辅助加分，不匹配不再扣分，也不再作为不推荐某种风味的原因。
- **复盘关联 kpro**：导入 `.klog` 后提示匹配结果，可确认打开或从收藏中手动选择对应 `.kpro`；未找到、文件名缺失或存在多个候选时，仍保留已导入的复盘。
- **界面与布局**：更新参数图标与动效，优化 iPhone 宽屏、折叠布局下的收藏抽屉、曲线预览与页面切换。
- **修复**：生成的曲线无法保存到机器、豆卡产地显示错误，以及参数输入与复盘页面交互问题。

## 1.9.x（2026-10-20 起）

包含 1.9.0，以及下列单独标注的开发中改动。

- **Siri 与快捷指令**：iOS 新增查询收藏曲线的养豆状态、列出已到期批次、开始养豆、打开收藏曲线四类操作；可按名称搜索收藏，并返回各批次剩余天数与到期时间。查询基于本地养豆记录，到期不代表最佳风味保证。
- **快捷开始养豆**：可指定 1–60 天养豆期限，并选择开启到期提醒；已有批次时再次确认，新增批次保留原有记录，通知未获授权时给出提示。
- **养豆提醒同步**：提醒开关与标题随养豆记录在设备间同步，兼容迁移已有提醒设置；同步或修改记录后重新安排本机通知，实际通知仍需本机授权。
- **收藏小组件**：新增“养豆中”标记，到期后自动更新状态，并调整打开与分享按钮的位置。

### 开发中（截至 2026-10-22）

- **收藏筛选**：移动端收藏支持按产地、冲煮法、处理法组合筛选；同一类别可多选，类别之间取交集。可从卡片摘取条件或通过菜单选择，点击或下拉条件标签可移除筛选，无匹配结果时可一键清空。
- **筛选交互**：新增筛选圆点提示与轻微呼吸动效；关闭收藏抽屉时退出条件摘取状态。
- **节奏说明**：macOS 与 iOS 的烘焙节奏说明浮层展示全部节奏选项及含义，便于比较自动与手动节奏。

## 说明

- 版本号来自 `kl-tools.xcodeproj/project.pbxproj` 的 `MARKETING_VERSION` 变更历史。
- 各版本按 `MARKETING_VERSION` 提升点划分；`chore: wip` 等开发中的中间提交不单独列出。
- 工程版本号及提交日期不代表 App Store 实际上架日期；开发中条目不表示已发布。
- 更详细的功能说明见站点中的专题文章，例如色值仪、kpro 文件名兼容性、烘焙复盘等。
