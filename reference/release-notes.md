# KL Profile 版本更新汇总

本文汇总 kl-tools（KL Profile）自 **1.1.1** 之后各版本的更新内容，按大版本（功能版本）组织，补丁版本并入所属大版本。版本号取自 Xcode 工程的 `MARKETING_VERSION` 变更历史；1.1.1 发布于 2026-08-23，当前版本为 1.6.3。

## 1.2.x（2026-08-27 起）

包含 1.2.0、1.2.1。

- **烘焙节奏（Pace）**：新增烘焙节奏参数，作为一条独立于产地、含水率与风味的调整基线。
- **官方模板与 RoR 调整**：引入官方模板库，新增曲线 RoR 调整与四阶段优化相关处理。
- **iPad 布局**：首次加入 iPad 布局适配。
- **修复**：风味目标存储、烘焙节奏与含水率回填、页面布局。

## 1.3.x（2026-08-31 起）

包含 1.3.0、1.3.1、1.3.2。

- **收藏（Profile Library）**：新增收藏功能，macOS 与 iOS 双端可用。
- **收藏同步**：收藏通过 CloudKit 在设备间同步。
- **重命名**：收藏中的 Profile 名称可重命名。
- **风味表现策略（FlavorExpression）**：引入独立于参数偏移的风味表现策略层。
- **修复**：RoR 平滑、iPad UI。

## 1.4.x（2026-09-05 起）

包含 1.4.0、1.4.1、1.4.2、1.4.3。

- **烘焙复盘（Recap）**：导入 `.klog` 生成烘焙日志，填写杯测反馈并生成自动调节建议。
- **复盘解锁**：复盘中的调节能力支持内购解锁。
- **kpro 文件名规则**：文件名改为与 Kaffelogic Studio 兼容（47 字节上限）。
- **klog / kpro 关联**：打开 `.klog` 时自动打开对应 `.kpro`；未匹配到时清空当前打开的 `.kpro`。
- **修复**：手动实际一爆、调整建议保存风味调节、自动调节文件名与 hash 逻辑、新建 Profile 按钮与收藏按钮解耦、macOS 鼠标滚轮事件、英文环境滚动字幕显示。

## 1.5.x（2026-09-12 起）

包含 1.5.0、1.5.1。

- **色值仪（Roast Color / Roast Score）**：新增相机色值仪，可测量整豆或咖啡粉的烘焙度。
- **小组件**：新增色值仪小组件（主屏 / 锁屏）与收藏小组件。
- **评分提示**：加入应用内评分提示逻辑。
- **修复**：导入 kpro 文件名逻辑、收藏抽屉交互性能。

## 1.6.x（2026-09-20 起）

包含 1.6.0、1.6.1、1.6.2、1.6.3，以及当前开发中的提交。

- **豆卡分享**：以豆卡二维码导出 / 导入收藏，支持从相册识别豆卡。
- **收藏管理**：收藏列表支持批量删除。
- **卡片动效**：收藏页面卡片翻转曲线。
- **参数变动浮层**：调整“高级微调”参数时，出现对应烘焙结果变化的浮层动效。
- **修复**：收藏同步无法打开、豆卡 UI、收藏列表性能优化。

## 说明

- 版本号来自 `kl-tools.xcodeproj/project.pbxproj` 的 `MARKETING_VERSION` 变更历史。
- 各版本按 `MARKETING_VERSION` 提升点划分；`chore: wip` 等开发中的中间提交不单独列出。
- 更详细的功能说明见站点中的专题文章，例如色值仪、kpro 文件名兼容性、烘焙复盘等。
