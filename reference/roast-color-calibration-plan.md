# 烘焙色值换算标定方案

色值仪测量的是相机估算的 CIELAB L\*、a\*、b\*。白纸或 18% 灰卡只负责光源校准，不提供烘焙度标准。正式标定需要采集 `(L\*, referenceScore)` 配对数据，优先使用同一批样本和同一专业仪器，覆盖浅、中浅、中、中深、深五档。

整豆与咖啡粉分别建模。每个样本在固定手机、光源、距离、容器和铺样方式下重复测量，使用中位数并保留波动范围。如果不同烘焙档位重叠，应先改善采集条件，不能用更复杂的公式制造分辨率。

当数据呈稳定单调关系时，使用相邻点的分段线性插值：

`S = S1 + (L - L1) / (L2 - L1) × (S2 - S1)`

初版不对标定范围外输入外推；结果显示 L\* 和“超出标定范围”。验证集必须与配对数据分离，并报告重复性、平均误差、最大误差和等级混淆情况。只有经过验证，才把连续分数作为用户的主要烘焙色值。

当前产品曲线是通用 iPhone 整豆经验曲线，用于估算，不宣称 Agtron 精度。未来取得真实配对数据后，只需替换 JSON 点位即可。
